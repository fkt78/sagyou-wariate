業務管理システム（sagyou-wariate）

GitHub: fkt78/sagyou-wariate のデータをブラウザで表示するには、開発サーバーを起動してください。

⚠️ 重要：まずサーバーを起動してください

「このサイトにアクセスできません」と表示される場合は、サーバーが起動していません。次のどちらかで起動してください。

方法A： Finder で sagyou-wariate フォルダを開き、「サーバーを起動.command」 または 「start-server.command」 を右クリック → 開く（初回は「開く」を選ぶ）。ターミナルが開き、サーバーが起動します。

方法B： Macの「ターミナル」アプリで以下を実行：

cd sagyou-wariate
npm install
npm run dev

サーバーが起動したら（ターミナルに URL が表示されたら）、下のボタンでアプリを開けます。サーバーはターミナルを閉じるまで動き続けます。.command が開けない場合は、ターミナルで chmod +x start-server.command を実行してから再度ダブルクリックしてください。

手順 2：ブラウザで開く

サーバー起動後、下のボタンをクリックするか、ブラウザのアドレス欄に http://localhost:3000 と入力してください。

アプリを開く（http://localhost:3000）

このアプリについて

店舗・担当者でログインし、「作業割り当て」や「ダッシュボード」を利用できます。データは Firebase（Firestore）に保存されます。
